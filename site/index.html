yon

Remote dev boxes over ssh. One bash script that turns a fresh VPS into a development home and gets you into its shell or its desktop with one command. For work that keeps running while the laptop is closed: coding agents, personal assistants, dev servers.

curl -fsSL https://yon.sh/install | sh
yon                  pick host, pick action
yon <host>           shell (tmux session)

yon add              new host -> ~/.ssh/config
yon install          set up a fresh box
yon desktop          xpra desktop through an ssh tunnel
yon open             a port of the box, in the browser
yon put              file or dir -> box
yon get              file or dir <- box
yon rm               drop a host yon added

Use cases

  • Coding agents on a VPS. Claude Code, Codex or OpenCode in a tmux session that survives disconnects and that any ssh client, a phone app included, reattaches to; yon box open 3000 shows the dev server they start.
  • A personal assistant that stays up. OpenClaw or Hermes Agent on a box where only ssh is reachable; yon box open 18789 brings the OpenClaw dashboard to the local browser.
  • A desktop on a server. XFCE in the browser, through an ssh tunnel, for GUI tools, sign-ins and CAPTCHAs.

Everything goes over ssh: no VPN, no hosted service, any provider.

What install does

New sudo user, keys-only ssh for that user alone, ufw with only ssh open, fail2ban, unattended upgrades, tmux on login, optionally Xpra and XFCE. It shows the plan and waits for a yes. Client: macOS or Linux. Box: Ubuntu or Debian.
