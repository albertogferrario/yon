homesh

Box di sviluppo remoti via ssh: shell persistente, desktop, provisioning. Uno script Bash; gli host sono quelli di ~/.ssh/config, nessun altro stato.

Install

./install.sh

Copia homesh in ~/.local/bin (/usr/local/bin da root). Non tocca altro.

Uso

homesh                  pick host, pick action
homesh add              new host -> ~/.ssh/config
homesh <host>           shell (tmux session)
homesh <host> desktop   xpra desktop through an ssh tunnel
homesh <host> init      provision a fresh box
homesh <host> rm        drop a host homesh added

<host> è un alias ssh o user@addr.

Box nuovo

homesh add

Chiede nome, indirizzo, utente (root su un server appena creato) e chiave, poi propone le azioni. init copia lo script sul box e lo esegue: utente con sudo, sshd con sole chiavi e un solo utente ammesso, ufw, fail2ban, tmux con aggancio al login, desktop a scelta. Mostra il piano e chiede conferma; al termine l'host passa al nuovo utente.

Note

  • add e rm scrivono in ~/.ssh/config solo blocchi marcati # homesh; copia precedente in config.homesh.bak.
  • init esclude ogni altro account da ssh, root compreso.
  • Desktop: servizio utente homesh-desktop.service, web client su localhost:14500 del box, sempre attivo. ^C chiude solo il tunnel.
  • Dopo un reboot la sessione tmux riparte vuota; il desktop riparte da solo.
  • Sul box: homesh init (root) e homesh desktop agiscono in locale.
